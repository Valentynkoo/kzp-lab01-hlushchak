## 3. Постановка задачі
Формат запису: `title:String; director:String; year:int; minutes:int; rating:double`.

Показники:
1. кількість коректних записів;
2. середній рейтинг;
3. найдовший фільм;
4. найстаріший рік.

## 4. Структура програми
- `Main` — розбір аргументів (`--help`, `--version`, `--input`, `--output`), керування потоком даних.
- `FileReport` — читання й запис файлів (`Path`, UTF-8).
- `MovieCatalogProcessor` — перевірка рядків, обчислення показників, форматування звіту.
- `ProcessingResult` — результат обробки.

Потік даних: `data/input.csv` → `FileReport.readLines` → `MovieCatalogProcessor.processLines` → `formatReport` → консоль і `out/report.txt`.
